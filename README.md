# POKER LAB 分享与发布

在线访问：`https://blkmanba1.github.io/poker-lab-gto-trainer/`

## 训练内容

- **题目练习**：混合、翻前、翻后三种题库模式，提交后显示教学频率和决策理由。
- **六人对战桌**：你与 5 个机器人连续对战，庄位每手轮转，筹码和本场盈亏连续计算。
- **完整牌局流程**：机器人自动行动；轮到你时可弃牌、过牌、跟注、加注、自定义下注或全下，牌局中不会提前显示推荐答案。
- **近似 GTO 策略**：机器人依据位置范围、牌力、听牌、底池赔率和随机混合频率行动；这是可对战的教学策略引擎，不是商业 Solver 的精确输出。
- **牌后复盘**：每手结束后可逐动作回放，查看节点参数、手牌与牌面、底池赔率、SPR、主策略、混合频率、偏差原因和下一次检查顺序；最近 20 手保存在当前浏览器中。
- **规则与摊牌**：使用本地打包的 PokerTools 引擎执行下注、边池和牌局状态，使用 `pokersolver 2.1.4` 计算牌型与胜负；第三方许可保存在 `vendor` 目录。
- **错题本**：偏离题目基线的固定题会自动收录；所有成绩与错题只保存在使用者自己的浏览器中。

## 最省事：直接发送文件

把 `poker-lab-share.zip` 发给朋友。对方解压后双击 `index.html` 即可使用，不需要安装软件，也不需要联网。

不要只单独发送 `index.html`，实战桌还需要同目录下的 `live-practice.css`、`live-practice.js` 和 `vendor` 文件夹。

## 推荐：发布成公开网址

### 方法一：GitHub Pages

1. 登录 GitHub，新建一个公开仓库，例如 `poker-lab`。
2. 把本目录的 `index.html` 上传到仓库根目录。
3. 打开仓库的 `Settings`，进入 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，然后保存。
6. 等待约 1-3 分钟，GitHub 会显示公开网址，通常是：

   `https://你的用户名.github.io/poker-lab/`

发布后，页面右上角的分享按钮会调用手机系统分享菜单；不支持系统分享时会复制当前网址。

### 方法二：Netlify Drop

1. 打开 `https://app.netlify.com/drop`。
2. 把整个 `gto-trainer` 文件夹拖到网页中。
3. 上传完成后会立即获得一个公开网址。

这种方式更快，但若要固定站点名称或长期管理，通常需要登录 Netlify。

## 更新网站

- GitHub Pages：更新 `index.html`、`live-practice.css`、`live-practice.js` 和 `vendor` 目录并提交，网址不变。
- Netlify Drop：把更新后的文件夹重新拖入站点部署页面。

## 数据说明

页面中的频率、机器人策略和复盘评分是用于练习决策结构的教学基线，不是指定抽水、下注树和范围条件下的精确 Solver 输出。公开分享时建议保留页面现有的数据边界说明。

复盘解释参考了本地德州扑克知识库中整理的“还原节点、比较范围、计算价格、构造价值与诈唬、最后检查阻挡牌”框架。网站只包含转译后的检查逻辑，不会上传父目录中的课程转写稿或完整知识库；机器人行动频率仍由站内近似策略引擎生成。

练习成绩、错题本和最近牌谱保存在使用者自己的浏览器 `localStorage` 中，不会上传到 GitHub，也不会在不同设备之间自动同步。
